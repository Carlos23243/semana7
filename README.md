## Descripción del programa

Este programa en Java demuestra el uso de constructores en Programación Orientada a Objetos. Se ha creado una clase llamada `Producto` que incluye:

- Un constructor por defecto
- Un constructor parametrizado
- Una sobrecarga del constructor con diferentes parámetros

También se muestra el uso de encapsulamiento y buenas prácticas como el uso de `this`, nombres descriptivos y comentarios explicativos.
